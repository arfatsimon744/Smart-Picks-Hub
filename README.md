# Smart Picks Hub

A responsive multi-niche affiliate discovery website starter built with HTML, CSS and vanilla JavaScript.

## Files
- `index.html` — homepage, categories, sample product picks, guides, newsletter demo
- `style.css` — responsive visual design
- `script.js` — mobile menu, category filters, search and save buttons
- `privacy.html` — starter privacy policy (review and customize before publishing)
- `disclosure.html` — affiliate disclosure page (update to match actual affiliate programmes)

## Run locally
Open `index.html` in a browser. For best results, use a local static server or deploy the folder to GitHub Pages or another static host.

## Before publishing
1. Replace the sample product cards with real products you have researched.
2. Replace each `href="#affiliate-note"` with your approved affiliate tracking URL only after the affiliate network approves you.
3. Update the privacy policy, disclosure, contact email, and site identity details.
4. Connect the newsletter form to a real email marketing provider or remove it. It is currently a demo and stores nothing.
5. Add original buying-guide articles and product images you have rights to use.
6. Check the current Awin programme terms and disclose affiliate relationships clearly.
7. Test all links, mobile layouts, keyboard navigation, image loading, and page speed.

## Important
This starter does not include real affiliate tracking, a backend, analytics, a mailing-list service, or product-price feeds. The sample products are design placeholders, not endorsements or verified deals.
